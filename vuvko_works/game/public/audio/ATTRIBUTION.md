# Audio credits

## Mission music — Eric Matyas

Five looping tracks from **soundimage.org**, by **Eric Matyas**:

- The Creeping Blob
- Factory On Mercury
- Eerie Cyber World
- Dizzybot
- Trouble on Mercury

His licence requires the credit to appear wherever the game does:

> Music by Eric Matyas
> www.soundimage.org

That line is on the game's credits screen. Re-check his current terms before
any release — they are stated on <https://soundimage.org/> and have changed
over the years.

## Menu music — 3D63

`menu-soft-millenium.mp3` is **Soft Millenium**, from the album **Analog Hack**
by **3D63** (produced, mixed and mastered by Andrea La Rosa), a name-your-own-
price release at <https://3d63.itch.io/analog-hack>.

Credit line: **Music by 3D63 — "Analog Hack"**.

**Permission, not a licence.** The page carries no licence document. The artist
has answered a question in the page's comments to the effect that use in a game
is fine so long as proper credit is given — which is a grant, but an informal
one, made to someone else, in a comment that can be edited or deleted.

This repository already draws that line elsewhere (`open-licensed.md`: _"that is
tolerance, not permission"_), so it is drawn here too. Before any public
release, get the permission in writing from the artist and record it in this
file, or replace the track. Checked 2026-09-11.

## Format

The `.ogg` files are as downloaded. The `.mp3` is a straight copy — not
re-encoded, not edited.
