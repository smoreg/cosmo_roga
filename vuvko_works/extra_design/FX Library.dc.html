derelict-fx

Every animation we settled on, extracted into one file you can drop into another project. One rule holds it together: nothing interpolates. Every visual state is a discrete frame held for a multiple of FRAME = 225ms. No easing, no tweens — that is what makes text, movement and combat read as one machine.

How the noise behaves

Unresolved characters render at dim: 0.42 and lock to full brightness left to right, so a reveal reads as a signal resolving. Width cannot change: each character becomes one of its own class and spaces and punctuation are left alone. Block glyphs are mixed in at blockChance: 0.3 — but only inside monospace runs, detected per element, because most UI faces lack them and the fallback font is wider.
