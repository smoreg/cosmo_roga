The reworked screens, running locally. They are React pages compiled in the browser, so this wants a server rather than file:// — the FX library is loaded as an ES module and the browser will not fetch one off the filesystem. React and Babel come from unpkg, so it also wants a network.

python3 -m http.server from this folder, then open localhost:8000.
