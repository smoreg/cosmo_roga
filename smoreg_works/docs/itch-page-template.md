# Шаблон страницы itch.io

Правило джема: **скриншоты обязательны**. Голосующий смотрит страницу до того, как играет —
страница набирает или теряет голоса до первого хода.

## Обязательное

- [ ] **Playable in browser** — HTML5-билд из `npm run zip`, загрузить как «This file will be
      played in the browser», размер вьюпорта выставить под экран игры (см. `SCREEN_WIDTH/HEIGHT`
      в `src/ui/theme.ts`, при fontSize 18 это примерно 1656×756 → ставить 1660×760)
- [ ] **4 скриншота**: экран старта, механика в действии, момент опасности, экран смерти
- [ ] **1 гифка твиста**, 5–8 секунд, — самый ценный элемент страницы
- [ ] Обложка 630×500
- [ ] Управление — прямо в описании, не в отдельном файле
- [ ] Пометка про сид в URL: `?seed=12345` воспроизводит забег (полезно для багрепортов)

## Структура описания

```markdown
**[Питч одним предложением.]**

Сделано за две недели для roguetemple's Fortnight 2.

### Твист

[Два-три предложения про механику. Без лора — про механику.]

### Управление

MOVE     hjkl / yubn / стрелки / нумпад
WAIT     . или 5 или пробел
ATTACK   шагнуть во врага
DESCEND  >  (стоя на лестнице)
HELP     ?

### Это traditional roguelike

Пошаговая, забеги без мета-прогрессии, permadeath, процедурная генерация уровней.
Умер — начинай заново.

### Известные проблемы

- [честно перечислить; голосующие ценят это и снижают штраф по Robustness]

### Технически

TypeScript + rot.js, без движка. Исходники: [ссылка]
`?seed=1234` в адресе воспроизводит забег точно — удобно для багрепортов.
```

## Проверка перед публикацией

- [ ] Открыть страницу в приватном окне — игра запускается без логина
- [ ] Проверить Chrome, Firefox, Safari
- [ ] Проверить на ноутбучном 1366×768: игра целиком в кадре, без скролла
- [ ] Клавиши со стрелками не скроллят страницу (`e.preventDefault()` — уже в `ui/input.ts`)
- [ ] Загрузить **утром 15-го**, не в 16:59
