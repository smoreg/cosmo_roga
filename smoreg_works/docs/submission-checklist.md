# Чеклист сдачи (день 13–15)

Про `games/salvor` — то, что сдаётся. Правило одно: **строка либо доказана названным тестом,
либо помечена «владелец»**. «Зелёный `npm test`» без имени файла ничего не доказывает: через
неделю никто не вспомнит, какой именно тест это ловил.

`[x]` — доказано на текущем `main`. `[ ]` — не сделано либо сделать может только владелец.
Числовых порогов баланса здесь нет намеренно: они живут в `games/salvor/tests/balance.test.ts`
и меняются, а чеклист, который приходится править вслед за числом, перестают читать.
