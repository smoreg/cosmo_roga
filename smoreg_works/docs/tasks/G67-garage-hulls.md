# G67 — Гараж: несколько корпусов и корпус-убийца

Статус: todo · Зависит от: G65 · Блокирует: — · Оценка: 4 ч · Пакет: `games/salvor` · Модель: fable

Владелец, 9.09: «так же можно хранить несколько корпусов; и сделай корпус-убийца — он очень
сильный, с особым оружием, но не может заниматься починкой дереликта».

## Сейчас

`Voyage.hull?: HullId` (`systems/voyage.ts:341`) — один корпус на рельсах, покупка при занятом
рельсе — `RACK_FULL`; рига дрона живёт на `game.player` (`rigOf`), а не в `Voyage`. Лестница
`HULLS` (`content/hulls.ts:128`) — SCRAPPER / SPARK / GHOST, различаются слотами, ядром, скоростью.

## Что сделать

1. `Voyage.hulls: Array<{ id: HullId; slots: (Slot | null)[]; core: number }>` + `active: number`;
   `hull` остаётся как геттер `hulls[active]?.id`, чтобы 40 мест чтения не переписывать. Покупка
   при занятом рельсе — **в гараж** (потолок `GARAGE_LIMIT = 3`), новая строка группы ДРОН
   «поставить на рельсы ▸» переключает: рига с `game.player` складывается в запись, запись
   активного разворачивается на игрока (`rigFrom`, `twist/rig.ts:152`). Гибель дрона — запись
   удаляется, следующий из гаража **не** встаёт сам: владелец выбирает.
2. **REAPER** в `content/hulls.ts`: цена 200, слоты 6, ядро 5, скорость 130, в стойке —
   `scythe` (реликвия G66: `attack [3, 7, 0]`, `relic: true`, не чинится) + THRUSTERS + SCANNER +
   PLATING + CELL, **без резака**, и флаг `hands: false`. С `hands: false` все оферты поднятия
   систем (`systems/ship.ts`, `objectiveHere` 332) серые с `why.hull.noHands`; резать двери он
   может (коса — `countsAs: "cutter"`), чинить корабль — нет. Это дрон для зачистки перед тем,
   как ТРУДЯГА пойдёт поднимать системы, — и первый настоящий повод держать два корпуса.
3. Панель буксира (`ui/tugboard.ts:31`): строка на каждый корпус в гараже, активный помечен.

## Баланс — риск высокий

Бот жмёт `enabled`-оферты: с 200 CR он купит REAPER и потом не сможет обезвредить ни один корабль
— так рушился прогон с пустым корпусом (owner-queue, девятый заход: 10 → 2 из 32). Правило
измерить **до** любой настройки: REAPER на полке только при `hulls.length ≥ 1` с руками (то есть
никогда как единственный дрон) — тогда бот его не берёт первым. Пороги те же: `balance.test.ts`,
`winnable.test.ts` (побед ≥ 3 на 200, уведено ≥ 10 из 32). Таблица до/после — в `Статус:`.
