# G33 — Robustness v3: реплеи рейса, fuzz по графу, персистентность, порча сейва

Статус: done (4.09) · Зависит от: G26, G19 · Блокирует: G13 · Оценка: 3 ч ·
Пакет: `games/salvor`

Иначе, чем в задаче: рейс «с продажей корабля» записан на рукодельном корпусе и без ALERT — ни
бот, ни скриптовый игрок не поднимает больше двух систем из трёх на сгенерированном грузовике
(первая поднятая система даёт тревогу 3, тревога 3 — это ENFORCER, и он разбирает ригу); реплеи
персистентности и половина fuzz'а гоняются с системой-заглушкой, держащей пол под счётом, иначе
забег кончается на первой гибели и второй вылазки в дереликт не бывает.

## Зачем

Состояние, которое живёт дольше корабля — дереликты, кредиты, гибели, призраки, заваренные
двери, — ровно тот класс состояния, где заводятся баги, которых не видит ни один тест на одну
вылазку.

## Что сделать

1. `tests/replay.test.ts`: три записанных рейса в `tests/fixtures/` (`careful` на фиксированных
   сидах): с гибелью и покупкой; с продажей корабля; с потерей корабля конкурентом. Каждый —
   бит-в-бит: граф, двери, кредиты, призраки, чартеры.
2. `tests/fuzz.test.ts`: 200 сидов × 500 случайных команд `randomBot` E14, включая станции и
   переходы; ни одного исключения, ни одного `NaN` в кредитах, ни одной сущности без отсека.
3. `tests/persistence.test.ts`: property «вход → действия → выход → вход» на 200 сидах: тот же
   граф, забранное не вернулось, мёртвое не ожило, вскрытое не заперлось, заваренное не
   расшилось, тревога по правилу, подкрепление только в `explored` и ≥ 2 от `entry`.
4. `tests/purity.test.ts`: `grep` по `packages/engine/src/rooms`, `games/salvor/src/{content,
   twist,systems}` — ни `Math.random`, ни `Date.now`, ни `document`, ни `window`.
5. Порча сейва: обрезанный, с мусорным `voyage`, с командой неизвестного `kind` — игра стартует
   новый забег и не падает.
6. Оверлей `SOMETHING BROKE` печатает `seed`, номер вылазки и номер дереликта (`ui/appstate.ts`,
   `crashSummary`).
