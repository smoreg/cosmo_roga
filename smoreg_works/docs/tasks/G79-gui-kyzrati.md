# G79 — Три правки экрана по Kyzrati: лог гаснет по ходу, история лога, цвет контакта

Статус: done 09.09 · Зависит от: G47, G68 · Блокирует: — · Оценка: 3 ч · Пакет: `games/salvor` · Модель: opus

Иначе, чем в задаче: цвет контакта — четыре полосы (целый `hpFull`, поцарапан `fg`, половина
`warn`, четверть `hpLow`), и он занял канал, где раньше строка в отсеке была красной, а за дверью
жёлтой; группу по-прежнему называет и считает красная/жёлтая линейка над блоком, так что сигнал
G47 остался. Из-за этого поправлено одно ожидание в чужом `pulse.test.ts` (было `warn`, стало
`hpFull`) — предмет теста, «пульс красит строку красным», сохранён. `PageDown` тоже читается
(листает вперёд), карточку не открывает. `HISTORY_ROWS` лежит в `ui/logline.ts`, а не рядом с
рисовальщиком: `ui/render.ts` уже импортирует `ui/appstate.ts`, и обратный импорт замкнул бы цикл.

Источник — **`docs/gui-guides.md`**, раздел 2 «Что применить» (до фриза) и раздел 5 «Лог сообщений».
Владелец: «правки делай». Правил не касается, только `ui/`.

## Что сделать
1. **Лог гаснет по ходу, а не по трём последним строкам.** Сейчас ярких строк ровно три
   (`LOG_FRESH` в `ui/web/screen.ts`, аналог в `ui/render.ts`), и ход из пяти строк уходит в серое
   наполовину — прямой источник «непонятно, что происходит». Поле `LogLine.turn` в движке уже
   есть: яркими остаются все строки текущего хода игрока, предыдущий ход — приглушён, старше —
   тусклый. Строки тона `alarm` (вводит G71) не гаснут никогда.
2. **История лога карточкой на `PgUp`** через существующий оверлей справки (`?` в `appstate.ts`):
   последние 200 строк `MessageLog`, `PgUp`/`PgDn` листают, `Esc` закрывает, ход не тратится.
   ASCII-вид по умолчанию и не имеет истории вообще.
3. **Цвет строки контакта по доле HP машины** (`ui/panel.ts`, блок контактов): `hpFull`/`hpLow` из
   `content/palette.ts` уже лежат; слов не добавляется, три языка не при чём.
4. Справка называет `?sound=off`, `?seed=`, `?view=`, `?training=1`, `?debug=1` — их сейчас негде
   узнать (0,3 ч).

Снято: цвет машины из её `fg` на схеме. Один красный на ряд машин — решение G40 п. 7 (владелец не
отличал коробку с карателем от коробки с ящиком); красный несёт «здесь беда», канал занят. Роль
машины уйдёт в форму тайла (G80), не в цвет.

**Не трогать:** `systems/**`, `content/**` кроме i18n, `packages/**`.

## Тесты
Лог: строки текущего хода все яркие, прошлого — приглушены, тон `alarm` яркий всегда (если тон уже
в движке; иначе тест пропускается с пометкой). История: `PgUp` открывает, 200 строк, `Esc`
закрывает, ход не тратится. Контакт: цвет меняется на порогах 100 % / 50 % / 25 %. Справка содержит
все пять параметров URL на трёх языках.
