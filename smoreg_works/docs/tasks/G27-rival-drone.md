# G27 — Конкурент: дрон чужого буксира

Статус: done 4.09 — заготовка интегрирована: `RIVAL` в `systems` после `POPULATE` и перед `SHIP`,
`onLevelEnter` первой строкой заводит карман через `startRival(game, wanted(game))`, глиф стал `r`.
Рейс не продаёт и не объявляет победу на корпусе, который увели (`rivalState(game).progress >=
OBJECTIVE_COUNT`), мелкие чартеры платятся; `snapshot` зеркалит прогресс в
`DerelictState.rivalProgress`. Иначе, чем в задаче: «всегда у smuggler/corsair» стало полем данных
`DerelictSpec.rival`, а не списком id внутри системы — тип корабля по GDD это данные, а `band`
не может назвать `r` (полоса — только то, что держит сам корпус). · Зависит от: G25, G14 ·
Блокирует: G34 · Оценка: 4 ч · Пакет: `games/salvor`

Инструкция интеграции, по которой это было сделано (оставлена как журнал):

1. **Подключить.** В `games/salvor/src/game.ts` — `RIVAL` в списке `systems` **после `POPULATE`**
   (ему нужны `room.data.systems`, которые POPULATE кладёт на первом входе) и перед `SHIP`:
   `[POPULATE, DOORS, ALERT, JAM, BLOOM, RIVAL, SHIP]`.
2. **Откуда `enabled`.** Полосу знает спека дереликта (G25), а карман `StoredShip.data` живёт
   только внутри `travelTo` — поэтому вопрос задаёт сам `RIVAL.onLevelEnter`: первой строкой,
   если кармана ещё нет, вызвать `startRival(game, wanted)`, где `wanted` — `true` для
   `smuggler`/`corsair` и `new Rng(game.currentShip.scheduleSeed).fork(0).chance(0.25)` для
   остальных (не `game.rng` — иначе включение конкурента перетряхивает все прочие броски забега).
   «Не больше одного живого» уже обеспечено: спавн только когда живого на борту нет.
3. **Потеря `neutralize`.** Признак — `rivalState(game).progress >= OBJECTIVE_COUNT` (тогда же
   выставлен `evac`). Рейс (G26) при расчёте на выходе не платит чартер `NEUTRALIZE` на этом
   корабле, мелкие остаются; `SHIP.beforeLevelLeave` не должен объявлять победу на корабле,
   который уже увели. Гибель по таймеру `evac` идёт обычным путём — `player.hp = 0`,
   `player.alive = false`, `game.onDeath(player)`, — так что `SHIP.onDeath` / `voyage.onDeath`
   подхватывают её без особого случая.
4. **Расхождение с GDD:** глиф `R` (в таблице «Машины» — `r`); один символ в `rivalKind()`.

## Зачем

«Можно встретить дрона другого буксира, который тоже пытается угнать корабль… тащиться за ним
и выбить собранный лут или прочистить им дорогу к рубке». Единственная механика, которая делает
время на корабле дорогим по сюжету. В v3 «прочистить дорогу» буквально: он `breacher` и режет
двери.

## Что сделать

1. `systems/rival.ts`:
   - `rivalKind()` собирается здесь (hp 7, 1d3, speed 110, `sight 1`, `breacher`, поведение
     `hunter` как транспорт: система каждый ход ставит `data.targetRoom` = отсек ближайшей
     неподнятой системы);
   - дойдя — работает 30 своих ходов (`afterActorTurn`), потом `rivalProgress++` и следующая;
     по дороге режет `locked`/`sealed` (движок, E18) — двери становятся `broken` и остаются;
   - несёт лут: 2 модуля прочности 2–3 (`data.loot`); удар по нему выбивает один в обломки
     отсека (`The rival drops a scanner.`); при `hp ≤ 3` — цель `entry`, дошёл — исчезает на эту
     вылазку;
   - `rivalProgress === 3` → `neutralize` потерян, лог `Another tug has the ship. You have
     twenty turns.`, `data.evac = 20`; на нуле — гибель дрона; мелкие чартеры остаются;
   - между вылазками `rivalProgress++` (`onLevelEnter`, `visits > 1`);
   - есть только там, где в полосе (`smuggler`, `corsair` — всегда; остальные — 25 % на вылазку,
     не больше одного живого).
2. `panelLines`: `RIVAL ▮▮▯`.

## Тесты

- Идёт к ближайшей неподнятой системе через запертую дверь, режет её за 3 хода; после 30 ходов
  работы прогресс +1; дверь остаётся `broken` после возврата.
- Удар выбивает ровно один модуль; при `hp ≤ 3` уходит и не появляется в эту вылазку.
- Три системы у конкурента → чартер потерян, окно 20 ходов, `leave` спасает дрона.
- Между вылазками +1; на кораблях без него в полосе — ни одного за 200 сидов.
- `careful` на 32 сидах контрабандиста: `stuck === 0`.
