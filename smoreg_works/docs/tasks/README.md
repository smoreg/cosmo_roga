# Задачи SALVOR — план для агентов (v3, граф отсеков)

Источник правды по дизайну — `docs/design-doc.md` (v3). Что из движка и игры переживает переезд
и с какими сигнатурами — `docs/engine-audit-v3.md`. Этот файл — порядок работ, зависимости и
протокол. Одна задача = один файл = одна сессия агента.

## Протокол агента

Перед началом прочитать **полностью**: `.claude/CLAUDE.md`, `docs/design-doc.md`, файл своей
задачи; для движковых и первых игровых задач — ещё `docs/engine-audit-v3.md` (§5 — сигнатуры,
которые обязательны). Потом — только те файлы, что названы в задаче.

Правила, которые ломать нельзя:

1. `packages/` не импортирует из `games/`. Движок не знает слов «дереликт», «чартер», «буксир»,
   «модуль», «ключ-карта». Понятие нужно движку — оно параметризуется данными из игры (строки
   `kind`, марки карточек, `Door.key`).
2. `sim/` и `rooms/` без DOM, без `Math.random()`, без `Date.now()`. Только `game.rng`.
3. Игра импортирует только `@jamrog/engine` и `@jamrog/engine/testing`.
4. Тесты обязательны в каждой задаче, пишутся **в той же задаче**, на текстовых фикстурах
   (`shipFromText` для графа, `fromAscii` — только для сеточного движка). `npm test` и
   `npm run typecheck` зелёные до слова «готово».
5. Ни одного TODO в коде. Неясно — задать вопрос в отчёте, не оставлять заглушку.
6. Тексты в игре — **английский**. Комментарии в коде — английский. Документы — русский.
7. Коммитить только если в поручении сказано; сообщения без упоминания AI.
8. Закончив — обновить строку `Статус:` в файле задачи (`todo` → `done`, дата, одна строка
   «что вышло иначе, чем в задаче»). Ничего больше в task-файле не править.
9. **Не тестировать игру в браузере.** Всё проверяется vitest'ом: чистые функции UI
   (`schematicLines`, `roomActions`, `toIntent`, …) покрываются напрямую, игра гоняется ботами и
   фикстурами. Скриншот делает владелец сам.
10. **`games/fortnight2` не трогать.** Это `submission-v1`. Вся v3 — в `games/salvor` и в
    `packages/engine/src/rooms/`. Сеточный `sim/` меняется только там, где задача явно это
    называет (типы `Twist`/`damage`/`save`/`levelstore`/`entity`/`kinds`), и все его 266 тестов
    остаются зелёными без правок.
11. Единственное разрешённое пересечение файлов внутри волны — одна строка `systems: […]` в
    `games/salvor/src/game.ts`: каждая система добавляет себя туда; конфликт при мерже —
    тривиальный, решает тот, кто мержит.

Если задача ломает существующий тест, который не относится к задаче, — не «чинить» тест, а
остановиться и написать почему.
