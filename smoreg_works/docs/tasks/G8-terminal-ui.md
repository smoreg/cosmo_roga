## Что сделать

1. `theme.ts`: `sidebarWidth 26`, палитра из G1; `SCREEN_WIDTH = 96`.
2. `render.ts`:
   - панель: заголовок `SALVOR  deck N/6`, `turn`, затем `panelLines` систем в порядке
     `[RIG, ALERT]` (уже отдают текст+цвет); строка с `◀` подсвечивать `accent`; сгоревшие —
     `burned`;
   - **схема палубы**: под заголовком `DECK` — зоны текстом. Алгоритм: BFS по рёбрам (шлюзам)
     от текущей зоны; каждая зона строкой `[CUR]` / `NAME` / `····` (не исследована: ни одна её
     клетка не `explored`), связи — `─` между именами в одной строке, `└─` для ветвей; максимум
     7 строк, дальше `…`. Достаточно читаемости, не красоты;
   - подписи зон на карте: имя зоны в `rect.x1+1, rect.y1` цветом `zone`, если зона исследована;
     не рисовать поверх сущностей;
   - `overlayGlyphs` с `remembered` — рисовать на `explored` клетках тусклым;
   - шлюз `=` цветом `accent`-приглушённым, переборка `|`;
   - экран смерти: `CORE BREACH` + `deck N · T turns · K machines scrapped · B modules burned`
     (`burnedCount` из `player.data.rig`); победа: `STATION SILENCED`;
   - вспышка: строку модуля, получившего урон в этот ход, рисовать `bad` один кадр (данные —
     из `panelLines`, поле `fg`).
3. `input.ts`: `g` → `interact`; `s`/`e`/`w`/`p` → `use` слота с нужным `kind` (поиск по
   `player.data.rig`; нет модуля → `none`, ничего не происходит, лог `No scanner installed.` —
   это UI-сообщение, через `game.log.add` без траты хода); `1`–`6` → `use` слота N−1.
   `KEY_HELP` обновить.
4. `app.ts`: `newGame(seed)` из `src/game.ts`; первое нажатие — заглушка под музыку (G12).
5. Проверить 1366×768: `fontSize 16` при `SCREEN_WIDTH 96` → 1536 px — много. Решение:
   `fontSize` подбирать из `window.innerWidth / SCREEN_WIDTH` (в `main.ts`, не в `sim`),
   минимум 12.
