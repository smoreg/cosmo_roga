# G12 — Адаптивная музыка и звук (опционально, последней волной)

Статус: done 4.09 · Зависит от: G30 · Блокирует: — · Оценка: 3 ч ·
Пакет: `games/salvor/music`

Иначе, чем в задаче: Strudel не рендерит в файл, поэтому экспорт делает свой офлайн-путь —
`@strudel/core` считает паттерн в Node, собственный синтезатор (`music/scripts/synth.mjs`)
играет его события, `sox` кодирует в `.ogg`; петли выходят бесшовными арифметически
(`--verify` меряет расхождение соседних итераций, вышло 0…6e-8), Strudel ставится вне
репозитория. Стингеров три, а не шесть: физические события (сгорание, дверь, сварка) отданы
ElevenLabs, музыкой остались только повороты забега — система поднята, дрон погиб, корабль
продан. Состояний пять, приоритет `tug` > `hunter` > `combat` > `hurt` > `explore`.

Делать только когда волна баланса закрыта. Первое под нож по `scope-rules.md`.
Состояния под v3: `tug` (буксир, тихо), `explore`, `combat` (машина в отсеке или видна сквозь
дверь), `hurt` (CORE ≤ 1 или ≤ 2 модулей), `hunter` (ENFORCER на корабле). Стингеры: сгорание
модуля, дверь вскрыта/заварена, поднятая система корабля, гибель дрона, продажа корабля, конец
забега.

## Что сделать

По `games/fortnight2/music/README.md` и скиллу `composing-music`: состояния из шапки задачи. Стингеры:
сгорание модуля (короткий электрический треск), спуск, смерть, победа. Бюджет ≤ 1.5 МБ,
`.ogg`. Подключение в `app.ts` на первом нажатии; переключение по `visibleMonsters().length`
и состоянию `rig`. Тест `packages/audio` уже держит кроссфейд — новых тестов не требуется,
кроме `tests/music-state.test.ts`: функция `musicStateFor(game)` чистая, покрыть 4 состояния.

## Уточнение владельца (день 3)

- **Музыка — в Strudel**, как и предписывает `games/fortnight2/music/README.md`: паттерны
  `.js` в `music/src/`, экспорт бесшовных `.ogg`-петель одной длины и темпа в
  `assets/audio/`. Стартовая точка владельца: пресет `s("[bd <hh oh>]*2").bank("tr909").dec(.4)`
  на <https://strudel.cc/> — драм-скелет, поверх которого скилл `composing-music` кладёт
  тему и пять состояний (`explore` / `combat` / `hurt` / `boss` / `safe`).
- **Звуковые эффекты — через ElevenLabs** (text-to-sound-effects API): сгорание модуля
  (электрический треск), удар по модулю, разбор обломков, импульс сканера, ЭМИ, сварка,
  рост тревоги, спуск, смерть, победа — ≤ 10 файлов, каждый ≤ 1.5 с, `.ogg` моно.
  **Ключ API лежит во втором мозге (`~/brain`, искать `/obsidian-find elevenlabs`) и/или в
  `~/.zshrc`.** Читать его только в переменную окружения при вызове, **никогда не печатать
  в лог/отчёт и не коммитить**; сгенерированные файлы — в `assets/audio/sfx/`, авторство
  и лицензия — в `assets/CREDITS.md` сразу.
- Бюджет по README: вся музыка ≤ 1.5 МБ; SFX — ещё ≤ 0.5 МБ.
- Подключение: `@jamrog/audio` (`AdaptiveMusic`) для музыки; для SFX — маленький
  `src/ui/sfx.ts` (DOM, `Audio`), события берёт из лога/`panelLines`, `sim/` не трогает.
