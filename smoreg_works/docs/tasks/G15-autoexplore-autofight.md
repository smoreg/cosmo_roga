# G15 — Автоисследование одной клавишей и Tab-автобой

(+ одна функция в `packages/engine`)

Запрос владельца после первой ручной пробы (день 3): «нужно автоисследование, пока не
встретишь что-то, одной кнопкой; и по Tab автодвижение с атакой в сторону врага, как в
Stone Soup». Приоритет — сразу после G10: это качество жизни, без которого голосующий
джема бросает игру на втором коридоре.

## Границы (чтобы не выпасть из «traditional»)

`docs/traditional-checklist.md` называет антипаттерном автобой и автоисследование, **снимающие
тактическое решение**. DCSS — эталон жанра — имеет и то и другое, потому что оба
останавливаются в момент, когда решение появляется. Правила:

- Автоисследование (`o`) делает **по одному шагу за нажатие-удержание** через обычный
  `playerCommand({kind:"move"})` и прекращается само, когда: в поле зрения появилась живая
  машина; открылись новые обломки/ящик/шлюз/люк; получен любой урон; тревога выросла;
  исследовать нечего (тогда — шаг к люку, и лог `Deck explored. The hatch is <dir>.`).
  Каждый шаг — честный ход: тревога тикает, машины ходят.
- Tab (`autofight`): одно нажатие = **один ход**: если враг рядом — атака бампом; если враг
  виден — один шаг к ближайшему видимому по Dijkstra-карте; врагов не видно — отказ
  `No target in sight.` без траты хода. Никакого «до смерти одного из».
- Оба — в `src/ui/`, поверх команд движка. `sim/` не знает про автоисследование: это
  UI-скрипт, который повторяет `move`, и его можно прервать любой клавишей.

## Что сделать

1. Движок, `sim/dijkstra.ts`: `exploreMap(level, from)` — Dijkstra-карта к ближайшим
   неисследованным проходимым клеткам (`explored === false`), сосед — обычный `bestStep`.
   Если в `dijkstra.ts` уже есть frontier-вариант (см. `docs/cookbook.md`, «авто-исследование»)
   — переиспользовать, не дублировать. Экспорт через `index.ts`. Тест на фикстуре: шаг ведёт к
   ближайшей неисследованной клетке, при полностью исследованной карте — `undefined`.
2. `src/ui/auto.ts`: чистые функции `exploreStep(game): Command | { stop: reason }` и
   `fightStep(game): Command | { stop: reason }` без DOM; условия остановки — список выше,
   каждое — отдельный тест (`tests/auto.test.ts` на `newGame` + фикстуры: появилась машина →
   стоп; обломки в поле зрения → стоп; урон → стоп; тревога +1 → стоп).
3. `src/ui/app.ts`: `o` запускает цикл — шаг, перерисовка, `setTimeout` 40 мс, следующий
   шаг, пока `exploreStep` не вернёт `stop` или не нажата любая клавиша (`Esc` в том числе).
   Таймер — только в UI, sim его не видит. `Tab` — один `fightStep`.
4. Причина остановки — в лог: `You see a security unit.` / `Something here: scrap.` /
   `Alert rising.`
5. `KEY_HELP` и `?`: `o explore · Tab fight`.

## Тесты

- `tests/auto.test.ts` — условия остановки, детерминизм (реплей команд, выданных
  автоисследованием, совпадает), `fightStep` без видимых врагов не тратит ход.
- Ручная проверка: 3 забега, автоисследование не приводит к смерти «в спину» — каждый раз
