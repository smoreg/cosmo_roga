# Чеклист: игра действительно traditional roguelike

Четвёртый критерий голосования ранжируют сами хосты, и slashie — автор Temple of the Roguelike.
Проверять раз в три дня, а не в последний день.

## Жёсткие требования джема

- [x] **Turn-based.** Мир не двигается, пока игрок не сделал ход. Нет таймеров, нет
      `requestAnimationFrame`-логики, нет реакции на скорость нажатий.
      → В каркасе: `Game.playerCommand()` — единственный вход, `Schedule` без часов.
- [x] **Run-based, без мета-прогрессии.** Ничего не переносится между забегами.
      Никаких unlock'ов, никакого «уровня аккаунта», никакого localStorage с прогрессом.
      Рекорд забега показывать можно — влиять на следующий забег он не должен.
- [x] **Permanent consequences.** Смерть — конец. Никакого undo, никакой загрузки предыдущего
      хода. Сейв только для «продолжить позже» и стирается при смерти.
- [x] **Значимый PCG.** Спросить себя: если заменить генератор на один рукодельный уровень,
      игра сломается? Если нет — PCG косметический, и это заметят.
- [x] **Один персонаж или малая партия.**

## Berlin Interpretation — высокоценные факторы

Неформальный канон 2008 года, на который ориентируется сообщество. Не обязателен, но
попадания читаются как «автор понимает жанр».

- [x] Случайная генерация уровней
- [x] Permadeath
- [x] Пошаговость, ход = дискретное действие
- [x] Не-модальность: перемещение, бой, всё — на одном экране, в одном режиме
- [x] Сложность за счёт тактики, а не рефлексов; управление ресурсами
- [x] Hack'n'slash: убийство монстров — основная деятельность
- [x] Исследование и раскрытие карты

## Низкоценные факторы (плюс, но не обязательны)

- [x] Один персонаж (не отряд)
- [x] Монстры ведут себя как игрок (те же правила, тот же планировщик)
- [x] Тактический вызов: первые уровни требуют выучивания
- [x] ASCII-графика
- [x] Подземелье из комнат и коридоров
- [x] Числа видны игроку (HP, урон, статы)

## Антипаттерны — что выдаёт «не traditional»

- ⛔ Мета-прогрессия любого вида — прямое нарушение правил джема
- ⛔ Реакция на скорость: уклонение в реальном времени, окно парирования
- ⛔ Модальный бой (отдельный экран боя)
- ⛔ Автобой / автоисследование, снимающие тактическое решение
- ⛔ Один рукодельный уровень с «рандомными» декорациями вместо PCG
- ⛔ Возможность откатить ход
