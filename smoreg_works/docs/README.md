Про структуру репозитория и границы между движком, играми и ассетами — корневой
`README.md` и `.claude/CLAUDE.md`.

   персистентный дереликт, экономика — из v2 без потерь (шаблон — `design-doc-template.md`)
4a. **`feedback/`** — дословные замечания владельца и их прочтение; источник требований v2/v3
   (`2026-09-03-duskers-schematic.png` — референс главного экрана)

   тестам; сигнатуры новых примитивов `rooms/`
4c. **`tasks/README.md`** — задачи для агентов, зависимости, **волны**, гейт 0 и гейт v3-core
