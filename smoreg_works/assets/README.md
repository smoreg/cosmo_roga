# Общие ассеты

Здесь лежит только то, что использует **больше одной игры**. Всё, что нужно одной, —
в `games/<id>/assets/`.

| Папка | Что кладём | Формат |
|---|---|---|
| `fonts/` | моноширинные шрифты для ASCII-рендера | `.ttf`, `.woff2` |
| `tiles/` | тайлсеты, спрайт-атласы | `.png` (без потерь), рядом `.json` с раскладкой |
| `audio/` | звуки и музыка | `.ogg` (в вебе лучше сжимается, чем `.wav`) |

## Правила

1. **Лицензия обязательна.** Рядом с каждым набором — `LICENSE.txt` или строка в
   `CREDITS.md` этой папки: автор, ссылка, лицензия. Джемовая страница на itch требует
   указания авторства, и искать его в дедлайн — худший момент.
2. **Оптимизировать до коммита.** PNG прогнать через `oxipng`/`pngcrush`, звук — в
   `.ogg` на 96–128 kbps. Бандл игры целиком должен оставаться в пределах пары мегабайт:
   голосующий, ждущий загрузки, уходит.
3. **Ничего не генерировать в рантайме из ассетов**, что можно сделать на этапе сборки.
4. **Vite копирует только то, на что есть импорт.** Файл, лежащий здесь и никем не
   импортированный, в сборку не попадёт — это нормально и специально.

## Как подключать

```ts
// из кода игры
import tilesUrl from "../../../assets/tiles/kenney-1bit.png";
// или, для файла этой игры:
import tilesUrl from "../assets/tiles.png";
```

Шрифты — через `@font-face` в `index.html` игры, с `font-display: block`, чтобы
ASCII-сетка не «прыгала» на первой отрисовке.
