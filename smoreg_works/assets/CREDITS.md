# Авторство ассетов

Заполнять сразу при добавлении файла, не перед сдачей.

| Файл | Автор | Источник | Лицензия |
|---|---|---|---|
| `audio/music/main.ogg` — трек `Dead Compartment` | Kirill Semenchenko (smoreg), владелец проекта | написан им в **Suno** (генеративная модель), исходник `main.mp3` не коммитится; в репозиторий кладётся только вырезанная петля | как у репозитория |
| `audio/sfx/{system,dead,sold}.ogg` | этот проект | паттерны Strudel `games/salvor/music/src/stingers/`, рендер `music/scripts/render.mjs` | как у репозитория |
| `audio/sfx/*.ogg` (остальные 10) | ElevenLabs Sound Effects, сгенерировано для этого проекта | text-to-sound-effects API, промпты — в `music/scripts/sfx.mjs` | по условиям ElevenLabs на сгенерированное аудио |

Чужого файла — сэмпла, трека, шрифта, спрайта — в сборке нет: всё аудио либо
сгенерировано для этого проекта, либо написано его автором. Но «всё написано
кодом» про музыку сказать нельзя, и раньше здесь было сказано именно это.
Честная раскладка такая:

- **Основная музыка — трек владельца**, сделанный им в Suno. Это генеративная
  модель: промпт и отбор — его, синтез — модели. Файл в игре — вырезанная из
  этого трека петля в 16 тактов (как именно вырезана — `games/salvor/music/README.md`).
- **Strudel остался только у трёх стингеров** (`system`, `dead`, `sold`): это
  по-прежнему паттерны `.js`, написанные для проекта и отрендеренные офлайн
  своим синтезатором — барабаны в них синтезированы кодом по описанию звука
  TR-909, банки сэмплов не использовались. Strudel (AGPL-3.0) — инструмент
  рендера: ставится вне репозитория, в сборку не попадает.
- Пять адаптивных петель, которые здесь стояли раньше, из игры убраны вместе с
  их паттернами: их место занял трек владельца. Ищутся в истории git.
