# Музыка игры

Исходники пишутся кодом, а не в DAW. Скилл `composing-music` (виден в этой сессии,
подключён симлинком из `~/code/playground/.claude/skills/`) закрывает жанр, тему,
аранжировку, форму и переходы; здесь — только пайплайн этого проекта.

```
music/src/        паттерны Strudel (.js) — это и есть исходник трека
../assets/audio/  экспортированные .ogg-петли, которые подключает игра
```

## Состояния

Адаптивный трек рогалика — это не пять разных мелодий, а **одна тема в пяти
трансформациях**, все в одном темпе. Смена темпа между состояниями запрещена: ощущение
разгона даёт дробление долей, а не BPM.

| Состояние | Когда | Жанровый пресет | Плотность атак/с |
|---|---|---|---|
| `explore` | по умолчанию, коридоры | dungeon synth / dark ambient | 2–5 |
| `combat` | в поле зрения живой враг | готик-рок / chiptune | 8–14 |
| `hurt` | HP ниже 35 % | тот же материал, снят верхний слой, добавлен пульс | 6–10 |
| `boss` | особый враг на уровне | всё вместе, добавлен низ | 12–18 |
| `safe` | лестница найдена, врагов нет | dungeon synth в мажорной окраске | 1–3 |

Стингеры (однократные акценты, не состояния): спуск на уровень, смерть врага-босса,
победа, смерть игрока.

## Как подключается

```ts
import { AdaptiveMusic } from "@jamrog/audio";

const music = new AdaptiveMusic({
  grid: { bpm: 96, beatsPerBar: 4, barsPerPhrase: 4 },
  layers: [
    { state: "explore", url: exploreUrl },
    { state: "combat", url: combatUrl, volume: 0.9 },
  ],
});

// в цикле хода: бой переключается по такту, исследование — по фразе
void music.to(game.visibleMonsters().length > 0 ? "combat" : "explore",
              game.visibleMonsters().length > 0 ? "bar" : "phrase");
```

Первый вызов обязан идти из пользовательского жеста — иначе браузер молча блокирует
автоплей. Практически: запускать музыку на первом нажатии клавиши, не на загрузке.

## Правила экспорта

1. **Петля должна быть бесшовной.** Проверять склейку по нулевой фазе, не «на слух»
   один раз.
2. **`.ogg`, 96–128 kbps, моно для фоновых слоёв.** Стерео оставить только ведущему.
3. **Все слои одной длины и одного темпа**, иначе кроссфейд разъедется.
4. **Бюджет:** вся музыка игры ≤ 1.5 МБ. Голосующий джема, который ждёт загрузку,
   уходит до первого хода.
5. Авторство сторонних сэмплов — в `assets/CREDITS.md` сразу, а не перед сдачей.
