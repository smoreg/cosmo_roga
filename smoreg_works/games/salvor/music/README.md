# Музыка и звук SALVOR

Основная музыка в игре — **трек владельца**. Раньше это были пять петель, написанных
паттернами Strudel и отрендеренных офлайн; они убраны, паттерны удалены, а от Strudel в
сборке остались только три стингера. Скилл `composing-music` по-прежнему закрывает жанр,
форму и переходы, здесь — пайплайн этого проекта.

```
music/src/stingers/   короткие однократные акценты, паттерны Strudel (.js)
music/scripts/        офлайн-рендер стингеров и генератор SFX
../../../assets/audio/music/main.ogg   основной трек, одна петля
../../../assets/audio/music/main.mp3   исходник владельца (в .gitignore, не коммитится)
../../../assets/audio/sfx/             эффекты ElevenLabs + рендер стингеров
```

Стингеры лежат рядом с эффектами, а не рядом с треком: для игры и то и другое —
однократный звук по строке лога, и проигрывает их один и тот же `sfx.ts`. Разное у них
только происхождение.

## Основной трек

`Dead Compartment` — сделан владельцем в **Suno** (теги исходника: `artist=smoreg`,
`comment=made with suno`). Авторство записано в `assets/CREDITS.md`, и записано честно:
промпт и отбор — его, синтез — модели. Это не «написано кодом», и заявку на джем будут
читать.

### Как из него сделана петля

Воспроизводимо, числа не округлять:

```
темп        74.9 BPM, 4/4, доля 0.8011 с
срез        от 23.208 с исходника, длиной 16 тактов = 64 доли = 51.272 с
```

И начало, и конец среза лежат на сильной доле — шов выбран как лучший из кандидатов, а не
взят с первого попавшегося места. Поэтому петля замыкается по тактовой сетке: доля
переживает стык, и всё, что игра делает «в такт», не разъезжается на каждом обороте.

```bash
sox assets/audio/music/main.mp3 assets/audio/music/main.ogg -C 2 trim 23.208 51.272
```

`-C 2` — качество Vorbis: 598 КБ стерео при бюджете 1.5 МБ. Моно трек не сводится
намеренно (`tests/audio-assets.test.ts` это и проверяет): ширина — часть материала, а
экономия 300 КБ бюджету не нужна.

## Что делает состояние забега

Пяти файлов нет — есть один, и состояние ведёт его **громкость**. `musicStateFor(game)`
остался тем же и остался чистой функцией с тестами (`tests/music-state.test.ts`);
изменилось только, что делают с ответом.

| Состояние | Когда | Громкость |
|---|---|---|
| `tug` | дрон на буксире (`isTug(game)`) | 0.70 |
| `explore` | по умолчанию, дереликт | 0.85 |
| `hurt` | CORE ≤ 1 или в раке ≤ 2 целых модулей | 0.90 |
| `combat` | машина в отсеке или видна сквозь открытую дверь | 1.00 |
| `hunter` | ENFORCER на корабле | 1.00 |

Приоритет при совпадении — `tug` > `hunter` > `combat` > `hurt` > `explore`. Буксир
перебивает всё: там безопасно по определению. Охотник перебивает бой: ENFORCER на борту —
худшее, что бывает в забеге, и трек должен быть на своём максимуме именно там. Бой
перебивает ранение, чтобы драка была слышна и у полумёртвого дрона; когда драка кончится,
музыка вернётся в `hurt` — и это ровно та драматургия, которая нужна.

Числа — те же, что раньше были потрековым трим-уровнем пяти петель. Переход не мгновенный:
громкость разгоняется линейно за две доли (`RAMP_SECONDS` в `src/ui/music.ts`), потому что
ступенька на границе хода слышна как дефект файла, а не как реакция игры.

## Сетка

```
bpm 74.9 · 4/4 · 16 тактов в фразе
доля  = 0.801068 с
петля = фраза = 16 тактов = 51.272 с
```

Ничего больше не кроссфейдится, так что сетка нужна не переходам, а **экрану**: вспышка
на появление машины планируется по playhead'у трека, чтобы попадать на долю
(`src/ui/pulse.ts`). Дробный BPM `@jamrog/audio` принимает — вся сетка там обычная
арифметика над `60 / bpm`, целочисленности нигде не требуется.

Числа должны совпадать в двух местах: здесь и в `GRID` в `src/ui/music.ts`. В
`music/scripts/render.mjs` теперь свой темп — он рендерит только стингеры и с треком не
связан.

## Материал

Осталось от прежнего саундтрека и продолжает работать: dark ambient / industrial,
**D phrygian** — вторая ступень (Eb) даёт то самое «что-то не так» без единого
диссонансного аккорда. Тема — шесть нот, называется «корпус»:

```
d3  eb3  d3  a2  g2  d2
0   +1   0   -3  -4  0      (ступени лада)
```

Контур: болезненный подъём на полтона, обвал на квинту вниз, возвращение домой. Три
стингера — фрагменты этой темы, поэтому они и садятся на трек, который писался отдельно:
общий лад и общая тоника. Пять состояний, которые тоже были её трансформациями, из игры
убраны — они в истории git.

## Стингеры

Однократные музыкальные акценты, не состояния. Их три, и все три — про повествование,
а не про физику:

| Файл | Событие | Материал |
|---|---|---|
| `system.ogg` | система корабля поднята | восходящая квинта `d3 → a3`, ярко |
| `dead.ogg` | дрон погиб | обвал `d3 → eb2 → d1`, фильтр закрывается |
| `sold.ogg` | корабль взят на буксир и продан | `d2 a2 d3 a3`, тепло, разрешение |

Всё физическое — сгорание модуля, удар, дверь, сварка, ЭМИ — это **SFX**, а не стингеры:
диегетический звук лучше делает генератор, чем синтезированный аккорд. Разделение
осознанное, см. ниже.

## SFX

Десять эффектов, каждый ≤ 1.5 с, генерируются ElevenLabs text-to-sound-effects скриптом
`scripts/sfx.mjs`. Таблица промптов — в самом скрипте, она же источник правды.

```bash
export ELEVENLABS_API_KEY=...        # ключ живёт в окружении, не в репозитории
node games/salvor/music/scripts/sfx.mjs            # только недостающие
node games/salvor/music/scripts/sfx.mjs --force    # перегенерировать всё
```

Ключ читается **только** из `process.env.ELEVENLABS_API_KEY`. Он никогда не печатается,
не пишется в файл и не попадает в коммит. Без ключа скрипт объясняет, что нужно, и выходит
с кодом 1, не трогая уже сгенерированные файлы.

Эффект привязан не к вызову из кода, а к **строке лога**: `sfxFor(lines)` разбирает
то, что игра и так написала игроку. Отдельного слоя событий нет и не надо — лог уже
есть единственное место, где перечислено всё, что произошло за ход.

## Экспорт

Strudel — браузерный, офлайн-рендера в файл у него нет. Поэтому экспорт двухступенчатый,
и паттерны остаются настоящим исходником, а не документацией к нему:

1. `@strudel/core` + `@strudel/transpiler` **вычисляют паттерн в Node** и отдают события
   (haps) — те же самые, что играл бы браузер.
2. Свой синтезатор (`scripts/synth.mjs`) превращает события в PCM, `sox` кодирует в
   `.ogg` моно.

```bash
# один раз: зависимости Strudel ставятся ВНЕ воркспейса, чтобы не тащить их в сборку
node games/salvor/music/scripts/render.mjs --setup

npm run music                    # все три стингера
node games/salvor/music/scripts/render.mjs --only dead
```

Хост Strudel по умолчанию — `~/.cache/salvor-strudel`; переопределяется `STRUDEL_HOME`.

**Чего этот путь стоит.** Тембры — приближение: рендер реализует синты, шумы, фильтры,
`shape`, `crush` и реверб по орбитам, но не сэмплы TR-909 и не VCSL. Барабаны
синтезированы по описанию 909, а не взяты из банка. Поэтому паттерны сознательно
ограничены тем, что рендер умеет, — вставить в `strudel.cc` их всё равно можно, и они
там зазвучат богаче, но структура, ритм, плотность и длина будут те же.

## Правила экспорта

1. **Петля замыкается по тактовой сетке.** Для трека это проверяет
   `tests/audio-assets.test.ts`: длина файла = 16 тактов при 74.9 BPM с точностью до 10 мс.
2. **`.ogg`.** Стингеры и эффекты — моно; трек — стерео, намеренно.
3. **Бюджет:** вся музыка ≤ 1.5 МБ, SFX — ещё ≤ 0.5 МБ. Голосующий джема, который ждёт
   загрузку, уходит до первого хода. Держит бюджет тот же тест.
4. Авторство — в `assets/CREDITS.md` сразу, а не перед сдачей. Если файл сделан моделью —
   так и писать, какой именно.

## Подключение

```ts
import { SalvorMusic, musicStateFor } from "./music.js";
import { SalvorSfx, sfxFor } from "./sfx.js";
```

`musicStateFor(game)` и `sfxFor(lines)` — чистые функции без DOM, и вся логика звука
живёт в них; классы вокруг них — только `Audio`-обвязка. Поэтому весь звук покрыт
vitest'ом, а браузер нужен только чтобы его услышать.

Оттуда же экран берёт часы: `SalvorMusic.untilBeat()` отдаёт, сколько миллисекунд до
следующей доли трека, читая `currentTime` играющего элемента. `undefined` — честный ответ
(звук выключен, автоплей заблокирован), и `ui/pulse.ts` в этом случае идёт по сетке, а не
выдумывает часы.

Первый вызов обязан идти из пользовательского жеста — иначе браузер молча блокирует
автоплей. Практически: звук стартует на первом нажатии клавиши, том самом, что убирает
титульную карточку.
