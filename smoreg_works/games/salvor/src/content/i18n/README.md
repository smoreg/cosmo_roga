# Языки SALVOR — как устроено и глоссарий

Три языка: **английский** (источник), **испанский**, **русский**. Переключение —
клавиша `L` на любом экране (цикл EN → ES → RU), `?lang=es` в адресе и
`localStorage["salvor.lang"]`. В хранилище лежит **только язык** — прогресса между
забегами в игре нет и не будет.

## Файлы

| Файл | Что это |
|---|---|
| `en.ts` | английский; **источник всех ключей** (`Key = keyof typeof EN`) |
| `es.ts`, `ru.ts` | `Table = Record<Key, string>` — нет ключа, не компилируется |
| `keys.ts` | `Key` и `Table` |
| `../../i18n.ts` | `t`, `tId`, `tIn`, `setLang`, `currentLang`, `cycleLang`, `initLang`, `LANGS` |

## Правило, которое нельзя нарушать

Ни одного `if (lang === …)` вне `src/i18n.ts`. Строка, видимая игроку, приходит
только из таблицы: `t("log.door.cut.done", { door })`. Новая строка — это три
правки в одном порядке: `en.ts`, `es.ts`, `ru.ts`.

Каталоги (`content/{modules,monsters,zones,hulls,derelicts,objectives}.ts`) держат
**английское имя как запасной вариант и как id** — движок носит `Room.name` и
`Entity.name` внутри себя, а `machineByName` ищет машину именно по имени. Экран
эти поля не читает: он спрашивает `moduleName()`, `roomName()`, `machineName()`,
`hullName()`, `derelictName()`, которые идут в таблицу через `tId(prefix, id, …)`.

## Мини-формат

- `{name}` — подстановка;
- `{n, one: дверь, few: двери, many: дверей}` — форма по числу; `#` внутри формы —
  само число. Английский и испанский различают `one`/`other`, русский —
  `one`/`few`/`many`. Библиотек нет, парсер — тридцать строк в `i18n.ts`.
- В форме нельзя использовать `,`, `:` и фигурные скобки.

## Ширины (проверяются `tests/i18n.test.ts`)

| Что | Предел | Где |
|---|---|---|
| строка панели | 28 (`PANEL_WIDTH` + колонка-отступ) | `ui/panel.ts` |
| строка двери в списке действий | 25 (`ACTION_WIDTH`) | `ui/actions.ts` |
| имя модуля | 10 | колонка стойки, `twist/rig.ts` |

Не влезает — **короче перевод**, а не шире панель.

## Тон

Телеграфный судовой журнал. По-русски это ещё и способ обойти падежи: имя из
таблицы всегда ставится в именительный, а фраза строится как запись —
`ПОДЛЕЖАЩЕЕ: событие, подробность` (`мусорщик: попадание, БРОНЯ (2/9).`).
В испанском по той же причине перед именем машины нет артикля: род каталог не
хранит. Русский — с «ё».
